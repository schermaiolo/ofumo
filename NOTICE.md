# Provenance

OFumo is a Touhou Fumo desktop pet whose movement and idle-state behaviour is
based on the classic public-domain `oneko` program.

The runtime keeps the oneko-style STOP/AWAKE/MOVE/idle state model and movement
mathematics while adding OFumo-specific sprites, animations, CMake build logic,
a PNG-to-XBM pipeline, and KDE Plasma Wayland support.

Reference implementation used for the movement/state behaviour:
Debian `oneko` 1.2.sakura.6 series (`oneko.c` / `oneko.h`).

## Artwork

The Koishi pixel sprites are Touhou derivative/fan artwork adapted for OFumo.
The source reference artwork comes from FumoFumos and is subject to the terms
published by its creator. The artwork is not automatically covered by any
license that may later be applied to OFumo's source code.

OFumo is an unofficial Touhou Project fan work and is not affiliated with
Team Shanghai Alice.
