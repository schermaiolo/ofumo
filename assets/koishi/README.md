# Koishi artwork

The PNG files in this directory are OFumo adaptations based on FumoFumos pixel
art and depict Koishi Komeiji from Touhou Project.

These image files are **not** covered by OFumo's MIT/Expat source-code license.

The FumoFumos artist permits the artwork for personal and non-commercial use.
That permission applies only to rights held by the artist and does not grant
rights to third-party characters or designs.

Artist terms:
https://fumofumos.com/about.html

Touhou Project fan-creator guidelines:
https://touhou-project.news/guidelines_en/

OFumo is an unofficial Touhou Project fan work and is not affiliated with Team
Shanghai Alice.
